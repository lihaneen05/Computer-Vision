# Computer Vision Lab Task 01

## Script Overview
The `images.py` script located in the `Files/` directory utilizes the OpenCV library (`cv2`) to read and display an image stored in the `Images/` folder.

## Folder Contents
The `Images/` folder contains sample image files used for testing OpenCV image loading capabilities:
* `sample1.jpg`: Sample test image 1
* `sample2.png`: Sample test image 2
